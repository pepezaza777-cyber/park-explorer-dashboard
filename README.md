# Park Explorer — สำรวจอุทยานไทย

แบบฝึกหัด Python + Pandas + Streamlit ใช้ข้อมูลนักท่องเที่ยวในอุทยานแห่งชาติ
เป็นคนละชุดข้อมูลกับตัวอย่างการจัดการขยะของอาจารย์

## ไฟล์ที่ต้องใช้
- `app.py` — โค้ดพร้อมคำอธิบายภาษาไทย
- `national_park_visitors.csv` — ไฟล์ข้อมูลจริง คงเนื้อหาต้นฉบับ
- `requirements.txt` — ไลบรารี โดยใช้ Pandas 2.3.3 ที่รองรับ Python 3.14
- `.streamlit/config.toml` — ธีมสีเขียวครีม ให้เก็บโฟลเดอร์นี้ไว้ด้วย
- `.gitignore` — ยกเว้น venv และไฟล์แคชจาก GitHub

## รันบนเครื่อง
หากมี venv อยู่แล้วให้เปิดใช้งานก่อน หากยังไม่มี ใช้ CMD ใน Windows รัน:

```bat
python -m venv .venv
.venv\Scripts\activate.bat
```

จากนั้นติดตั้งไลบรารีและเปิดเว็บ:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

กด Ctrl+C ใน Terminal เพื่อหยุดเว็บ
อัปโหลด app.py, CSV, requirements.txt และโฟลเดอร์ .streamlit บน GitHub และเลือก `app.py`
เป็น Main file path ใน Streamlit Community Cloud โดยเลือก Python 3.12

## สิ่งที่แสดง
หน้าใหม่ใช้ตัวกรองแนวนอน หัวเรื่องภาพภูเขา และธีมสีเขียวครีม
แบ่งเป็นแท็บภาพรวมการเดินทาง สำรวจรายเดือน และข้อมูลและแหล่งที่มา

1. กราฟพื้นที่และเส้นแนวโน้มจำนวนผู้เข้าชมรายปีงบประมาณ
2. กราฟแท่งอุทยานที่มีผู้เข้าชมสูงสุด รวมปีที่เลือก
3. กราฟเส้นจำนวนผู้เข้าชมรายเดือน แยกเส้นตามปีงบประมาณ

ตัวกรอง: ปีงบประมาณ สังกัด ชื่ออุทยาน และจำนวนอันดับในกราฟแท่ง
ทุกกราฟและตัวเลขสรุปใช้ข้อมูลหลังกรอง
ปีต้องเลือกอย่างน้อยหนึ่งปี ส่วนสังกัดและอุทยานเว้นว่างหมายถึงทั้งหมด

## แหล่งข้อมูลและความหมาย
- ชุดข้อมูล: ข้อมูลนักท่องเที่ยวในอุทยานแห่งชาติ
- หน่วยงาน: กรมอุทยานแห่งชาติ สัตว์ป่า และพันธุ์พืช
- หน้าชุดข้อมูล: https://data.go.th/th/dataset/gdpublish-stat-tourism
- ไฟล์ต้นทาง: https://catalog.dnp.go.th/dataset/91d66c6a-5b88-41ee-8597-11be8aec5aa6/resource/be300299-f9a3-4eac-b558-0c088dd77a64/download/tourism59-68.csv
- ดาวน์โหลดวันที่ 11 ตุลาคม 2569
- สัญญาอนุญาตตามหน้าชุดข้อมูล: Open Data Common
- ข้อมูลปีงบประมาณ 2559–2568 จำนวน 1,543 แถวต่ออุทยานต่อปี มีเดือน 12 คอลัมน์
- หน่วย: คน เป็นยอดจำนวนผู้เข้าชม ไม่ใช่จำนวนบุคคลที่ไม่ซ้ำกัน
- ปีงบประมาณ 2568 หมายถึง ตุลาคม 2567 ถึงกันยายน 2568
- ชื่ออุทยานคงตามต้นทาง ไม่รวมชื่อที่ต่างกันให้เป็นแห่งเดียวโดยอัตโนมัติ
- ศูนย์คงไว้ตามต้นฉบับ ไม่ตีความสาเหตุเอง; ค่าว่างหรือข้อความที่แปลงเป็นตัวเลขไม่ได้ไม่แทนด้วยศูนย์

โค้ดอ่าน CSV ด้วย Pandas และใช้ `melt` แปลงคอลัมน์เดือนเป็นแถว
จากนั้นใช้ `groupby` และ `sum` เพื่อสรุปข้อมูลและสร้างกราฟด้วย Plotly
